# คู่มือผู้สมัคร

1. เปิดหน้าเว็บ ดูสายงาน ประเภทการจ้าง หน่วยงาน และสถานะ กดตำแหน่งเพื่ออ่านคุณสมบัติ เอกสาร และกำหนดเวลา
2. สมัครสมาชิก: คำนำหน้า ชื่อ นามสกุล อีเมล โทรศัพท์ รหัสผ่านอย่างน้อย 8 ตัว ยืนยันรหัสผ่าน และรับทราบนโยบาย ใช้อีเมล/รหัสผ่านเข้าสู่ระบบ ไม่มีช่องกรอก OTP
3. ไป “สมัครตำแหน่งนี้” กรอกข้อมูลส่วนตัว วันเกิดในช่องปฏิทินเป็น ค.ศ. วันที่แสดงในเอกสารเป็น พ.ศ.
4. กรอกการศึกษา เพิ่มหลายรายการได้ และประสบการณ์ถ้ามี เลขบัตรประชาชนปรากฏเฉพาะประกาศที่จำเป็นต้องเก็บ
5. ตรวจตำแหน่ง กดถัดไปเพื่อบันทึกร่าง ร่างที่บันทึกแล้วอยู่ใน “ใบสมัครของฉัน”
6. แนบเอกสารบังคับ PDF/JPG/PNG ตามขนาดตำแหน่ง รูปถ่ายต้อง JPG/PNG รอการตรวจไฟล์จนสำเร็จ หากผิดพลาดกดลองใหม่
7. ตรวจทาน รับรองความถูกต้องและรับทราบนโยบาย กด “ยืนยันส่งใบสมัคร” เลขเช่น KKC-2569-000001 จะออกเมื่อฐานข้อมูลบันทึกสำเร็จ
8. หากเครือข่ายหลุด ให้เปิดใบสมัครของฉันตรวจเลขและสถานะก่อน ระบบตรวจการส่งซ้ำ ไม่ต้องสร้างใบสมัครใหม่
9. ค่าธรรมเนียมแสดงเฉพาะตำแหน่งที่เปิดใช้ อัปโหลดสลิป กรอกยอด เวลา และอ้างอิง สถานะรอตรวจจนเจ้าหน้าที่อนุมัติ
10. เมื่อได้รับคำขอแก้ไข เปิดใบสมัคร → แก้ไข แก้ตามข้อความภายในเวลาที่แจ้ง แล้วส่งอีกครั้ง เลขผู้สมัครเดิมคงอยู่
11. ใบสมัคร/PDF: เปิดใบสมัคร → ใบสมัคร/PDF → พิมพ์/บันทึก PDF เลือก A4 ปิด header/footer ของ browser เพื่อจัดหน้าให้เรียบร้อย
12. บัตรสอบจะมีเมื่อเจ้าหน้าที่กำหนดเลขและเผยแพร่กำหนดการแล้ว เปิดบัตรสอบและพิมพ์นำไปตามประกาศ
13. ลืมรหัสผ่าน: กดลืมรหัสผ่าน กรอกอีเมล เปิด link ในจดหมาย ตั้งรหัสใหม่ หากหมดอายุขอลิงก์ใหม่ หลังเปลี่ยนต้อง sign-in อีกครั้ง
14. เปลี่ยนข้อมูลทั่วไปได้จากโปรไฟล์ ใบสมัครที่ส่งแล้วใช้ snapshot ณ เวลาส่ง จึงไม่เปลี่ยนตามโปรไฟล์
15. ใช้ “ออกจากระบบ” เมื่อใช้งานเครื่องร่วมกัน

สถานะ: แบบร่าง → ส่งใบสมัครแล้ว → กำลังตรวจ → ต้องแก้ไข/ผ่าน/ไม่ผ่าน ถอนใบสมัครได้ก่อนผลคุณสมบัติสิ้นสุด การถอนต้องกดยืนยันในหน้าใบสมัคร
