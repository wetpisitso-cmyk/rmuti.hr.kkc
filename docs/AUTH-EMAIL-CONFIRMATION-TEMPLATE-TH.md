# แม่แบบอีเมลยืนยันการสมัครสมาชิก RMUTI KKC

หัวเรื่อง: ยืนยันอีเมลสำหรับระบบรับสมัครบุคลากร RMUTI KKC

สวัสดีครับ/ค่ะ

ขอบคุณที่ลงทะเบียนในระบบรับสมัครบุคลากรออนไลน์ มหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน วิทยาเขตขอนแก่น

โปรดคลิกลิงก์ยืนยันอีเมลที่ Supabase สร้างให้ เพื่อยืนยันว่าคุณสามารถเข้าถึงกล่องจดหมายดังกล่าวได้ ก่อนเข้าสู่ระบบสมัครงาน

หากคุณไม่ได้ลงทะเบียน ไม่จำเป็นต้องดำเนินการใด ๆ และไม่ควรส่งต่อลิงก์ยืนยันให้ผู้อื่น

ระบบรับสมัครบุคลากรออนไลน์ RMUTI KKC
(อีเมลฉบับนี้มีไว้เพื่อยืนยันบัญชี ไม่ใช่การแจ้งผลการสมัครงาน)
