# คู่มือเจ้าหน้าที่และผู้ดูแล

ผู้สมัครทุกคนเริ่มเป็น applicant เจ้าของโปรเจกต์ตั้ง admin คนแรกตาม README ผู้ดูแลมอบสิทธิ์ HR รายบุคคลจากหน้าบัญชีและสิทธิ์

## เตรียมรอบรับสมัคร

1. เพิ่มหน่วยงาน
2. เพิ่มรอบ: ชื่อ ปี พ.ศ. เวลาเปิด/ปิด จำนวนตำแหน่งสูงสุดต่อคน และเผยแพร่
3. เพิ่มตำแหน่ง: รอบ หน่วยงาน สายงาน ประเภทการจ้าง อัตรา วุฒิ/สาขา เงื่อนไข และเอกสารบังคับ
4. ถ้าจะเก็บเลขบัตรประชาชน ต้องมีเหตุผลตามประกาศแล้วเปิดฟิลด์ หากไม่เปิด ระบบไม่บันทึกค่าแม้ส่ง API มา
5. กำหนดขนาดไฟล์ 1–10 MB ข้อมูลเอกสารแต่ละประเภทต้องมีประเภทไม่ซ้ำและชื่อที่ผู้สมัครเข้าใจ
6. ค่าธรรมเนียม 0 คือไม่เรียกเก็บ หากมี ใส่ยอดและวิธีชำระ/บัญชี/ลิงก์ QR ตามประกาศจริง
7. เผยแพร่ทั้งรอบและตำแหน่งจึงปรากฏให้ประชาชน เหตุผลที่ใช้ “เก็บถาวร” คือรักษาใบสมัครและประวัติเดิม

## ตรวจใบสมัคร

- ใช้ตัวกรองปี รอบ ตำแหน่ง หน่วยงาน สถานะ และวันที่ ทุกการ์ด กราฟ ตารางเปลี่ยนตามตัวกรองเดียวกัน
- ค้นชื่อหรือเลขผู้สมัคร มี debounce เรียงลำดับและเปลี่ยนหน้าได้
- เปิดรายการ ตรวจข้อมูลการศึกษา/ประสบการณ์ และ preview เอกสาร ไม่โหลดเอกสารผู้สมัครทุกคนพร้อมกัน
- เปลี่ยน “ส่งแล้ว” เป็น “กำลังตรวจ” ก่อนให้ผล
- ขอแก้ไข: กรอกรายการที่ต้องแก้และเวลาในอนาคต ผู้สมัครเห็นข้อความนี้และแก้ได้จนหมดเวลา แม้รอบปกติปิดแล้ว
- ไม่ผ่านต้องระบุเหตุผล ผ่านคุณสมบัติต้องยืนยันการชำระก่อนหากมีค่าธรรมเนียม
- บันทึกภายในแยกจากข้อความผู้สมัคร ห้ามใส่บันทึกภายในในช่องที่เผยให้ผู้สมัครเห็น
- สลิป: เปิดรูป ยอด เวลา และอ้างอิง เลือกยืนยัน/ปฏิเสธ หากปฏิเสธกรอกเหตุผล ระบบตรวจเลขอ้างอิงซ้ำและไม่อนุมัติจากภาพอัตโนมัติ

## การสอบและผล

1. สร้างกำหนดสอบให้ตรงตำแหน่ง ใส่วันเวลา สถานที่ ข้อปฏิบัติ
2. กำหนดเลขประจำตัวสอบให้ใบสมัครที่ผ่านคุณสมบัติ เลขซ้ำในกำหนดสอบเดียวกันไม่ได้
3. เผยแพร่กำหนดการจึงเปิดบัตรสอบให้ผู้สมัคร
4. ใส่คะแนน 0–100 และผล ได้รับคัดเลือก/สำรอง/ไม่ได้รับคัดเลือก ผลเป็นร่างก่อนเผยแพร่
5. เปิดประกาศและการเผยแพร่ → ตรวจร่าง/เผยแพร่ เลือกตำแหน่งและชนิดผล ตรวจรายชื่อ แล้วกดเผยแพร่
6. ตารางสาธารณะมีเฉพาะเลขผู้สมัคร ชื่อ และผล ไม่ใช้ตารางใบสมัครทั้งหมดเป็น public API
7. ถ้าแก้ผลคะแนนที่เผยแพร่แล้ว ต้องตรวจและเผยแพร่ผลใหม่อีกครั้งเพื่อปรับประกาศสาธารณะด้วย

## รายงานและตั้งค่า

- CSV ส่งออกทุกหน้าตามตัวกรอง มี BOM สำหรับ Excel และป้องกันข้อความถูกอ่านเป็นสูตร
- PDF หน้ารายงานใช้ Print to PDF แสดงมหาวิทยาลัยและข้อมูลหน้าปัจจุบัน หากต้องการรายการทั้งหมดใช้ CSV
- ใบสมัคร A4 เป็นเอกสารรับใบสมัคร **ไม่ใช่ใบเสร็จรับเงิน** การออกเอกสารรับชำระต้องผ่านระบบ/ขั้นตอนการเงินที่หน่วยงานกำหนด ไม่สร้างใบเสร็จปลอมจากสลิป
- ตั้งค่าโทรศัพท์ อีเมล ที่อยู่ นโยบายฉบับจริง และระยะเวลาเก็บข้อมูล ค่า retention เป็นนโยบายอ้างอิง ไม่มี auto-delete
- ดู audit log และคิวส่งอีเมลในหน้าตั้งค่า ผู้ใช้ทั่วไปแก้ประวัติไม่ได้
- อีเมลรอตั้ง provider ที่อนุมัติ ส่วนแจ้งเตือนในเว็บทำงานได้ทันที
